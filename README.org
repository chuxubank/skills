* Skills
Misaka's agent skills

** Available skills
- =worktree-handoff=: Coordinator-only handoff for features, fixes, and other
  independent work: Worktrunk worktree first, then its matching Luvus workspace
  agent. Explicit delegation only; assigned workers execute, never recurse.
- =bugfix-delivery=: Deliver Feishu Project bug fixes through Worktrunk,
  Luvus-managed Pi execution, GitLab MR gates, status comments, and cleanup.
- =grok-subagent=: Delegate focused implementation to Grok Build CLI and
  independently review and verify its changes.
- =adb-device-unlock=: Unlock an authorized Android device with adb before UI
  automation.
- =apk-device-install=: Install and verify an APK. Classify a USB confirm
  as countdown or staying; do not keep a per-OEM tap table.
- =mitmproxy-mock=: Simulate HTTP APIs with the bundled mitmproxy WireGuard
  addon and check the client behavior that follows.

** Deprecated skills
